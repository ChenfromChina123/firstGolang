# 云空间显示与管理员页面开发计划

## Context

用户需求：
1. 前端显示用户已使用的云空间（顶部导航栏）
2. 专门的管理员页面开发（用户管理 + 系统统计总览 + 文件管理 + 分享管理）

现状分析：
- `/api/me` 只返回 user_id/username/role，无存储用量信息
- 后端无存储用量统计 API（无 SUM(size) 查询）
- db.go 有 CountUsers 但无 ListUsers
- admin 权限是内联检查（`role == "admin"`），无专门中间件
- 前端无 admin.html，index.html 导航栏有 `#user-info`/#user-name/#user-role 元素
- admin 已支持查看所有文件、所有回收站（通过 `?all=true`）

## 实施方案

### 第一部分：存储用量显示（顶部导航栏）

#### 后端改动

**1. db.go 新增存储用量统计方法**

文件：`internal/store/db.go`

```go
// GetUserStorageUsage 统计指定用户的存储用量
// owner 为空时统计全局（admin 用）
type StorageUsage struct {
    UsedSize   int64 `json:"used_size"`    // 已用空间（字节，不含回收站）
    FileCount  int64 `json:"file_count"`   // 文件数
    TrashSize  int64 `json:"trash_size"`   // 回收站大小（字节）
    TrashCount int64 `json:"trash_count"`  // 回收站文件数
}

func (db *DB) GetUserStorageUsage(owner string) (*StorageUsage, error)
```

SQL 查询：
- 正常文件：`SELECT COALESCE(SUM(size),0), COUNT(*) FROM files WHERE owner = ? AND deleted_at IS NULL AND status = 'completed'`
- 回收站文件：`SELECT COALESCE(SUM(size),0), COUNT(*) FROM files WHERE owner = ? AND deleted_at IS NOT NULL`
- owner 为空时去掉 WHERE owner 条件（admin 全局统计）

**2. 新增存储用量 API**

文件：`internal/handler/settings.go`（复用现有 settings handler）

新增端点：`GET /api/storage-usage`
- 普通用户：返回自己的用量
- admin：默认返回全局用量，可通过 `?username=xxx` 查看指定用户
- 响应：`{"used_size": 12345678, "file_count": 42, "trash_size": 1024, "trash_count": 3}`

**3. /api/me 扩展（可选）**

在 `/api/me` 响应中加入 `storage_usage` 字段，减少前端请求次数。或保持独立接口，前端并行调用。选择独立接口（职责分离，缓存策略不同）。

#### 前端改动

**1. index.html 导航栏新增用量显示**

在 `#user-info` 区域新增：
```html
<span class="storage" id="user-storage" hidden>已用 0 B</span>
```

**2. app.js 登录后获取用量**

- `checkLogin()` 成功后调用 `fetchStorageUsage()`
- `fetchStorageUsage()` 调用 `/api/storage-usage`，更新 `#user-storage` 显示
- 上传完成、删除文件、恢复文件后调用 `fetchStorageUsage()` 刷新
- 复用现有 `fmtSize()` 格式化大小

### 第二部分：管理员页面开发

#### 后端改动

**1. db.go 新增管理员查询方法**

文件：`internal/store/db.go`

```go
// ListUsers 列出所有用户（admin 用，不含密码哈希）
func (db *DB) ListUsers() ([]*model.User, error)

// ListAllShares 列出所有分享（admin 用）
func (db *DB) ListAllShares() ([]*model.Share, error)

// GetSystemStats 系统总览统计
type SystemStats struct {
    TotalUsers     int64 `json:"total_users"`
    TotalFiles     int64 `json:"total_files"`
    TotalSize      int64 `json:"total_size"`
    TotalShares    int64 `json:"total_shares"`
    TrashFiles     int64 `json:"trash_files"`
    TrashSize      int64 `json:"trash_size"`
    ActiveUsers    int64 `json:"active_users"`  // status='active'
    DisabledUsers  int64 `json:"disabled_users"`
}
func (db *DB) GetSystemStats() (*SystemStats, error)
```

**2. 新建管理员 handler**

文件：`internal/handler/admin.go`（新建）

```go
type AdminHandler struct {
    db *store.DB
}

// 路由：
// GET    /api/admin/stats              - 系统统计总览
// GET    /api/admin/users              - 用户列表（含各自用量）
// POST   /api/admin/users/{id}/status  - 禁用/启用用户
// POST   /api/admin/users/{id}/reset-password - 重置用户密码
// GET    /api/admin/shares             - 所有分享列表
// DELETE /api/admin/shares/{id}        - 删除分享
```

权限检查：每个方法开头检查 `role := auth.RoleFromContext(r.Context()); if role != "admin" { return 403 }`

**3. main.go 注册路由**

```go
adminHandler := handler.NewAdminHandler(db)
mux.Handle("/api/admin/", adminHandler)  // /api/admin/* 赘认证中间件
```

#### 前端改动

**1. 新建 admin.html**

文件：`web/admin.html`（新建）

页面结构：
- 顶部导航：返回主控制台 + 管理员标识
- Tab 切换：系统总览 | 用户管理 | 文件管理 | 分享管理

**系统总览 Tab**：
- 统计卡片：总用户数、总文件数、总存储大小、分享数、回收站大小
- 调用 `GET /api/admin/stats`

**用户管理 Tab**：
- 表格列：用户名、邮箱、角色、状态、已用空间、文件数、创建时间、操作
- 操作按钮：禁用/启用、重置密码（弹窗输入新密码）
- 调用 `GET /api/admin/users`

**文件管理 Tab**：
- 复用 index.html 的文件树组件，但显示所有用户的文件
- 每个文件显示 owner 列
- 调用 `GET /api/files`（admin 默认返回所有）

**分享管理 Tab**：
- 表格列：分享ID、创建者、类型、名称、下载数、有效期、操作
- 操作按钮：查看分享页、删除分享
- 调用 `GET /api/admin/shares`

**2. index.html 新增管理员入口**

在 `#user-info` 区域，role=admin 时显示：
```html
<a href="/web/admin.html" class="admin-link" id="admin-link" hidden>管理后台</a>
```

app.js 中 `checkLogin()` 检测到 role=admin 时显示 `#admin-link`。

**3. admin.html 权限守卫**

页面加载时调用 `/api/me` 检查 role，非 admin 重定向到 `/web/index.html`。

### 验证方案

#### 本地验证（项目规则：本地启动验证再部署）

1. **编译验证**：`go build ./cmd/server/` 无错误
2. **本地启动**：`./server.exe`（SQLite 模式）
3. **存储用量 API**：
   - 登录普通用户 → `GET /api/storage-usage` → 返回自己的用量
   - 登录 admin → `GET /api/storage-usage?username=xxx` → 返回指定用户用量
4. **管理员 API**：
   - `GET /api/admin/stats` → 返回系统统计
   - `GET /api/admin/users` → 返回用户列表
   - `POST /api/admin/users/{id}/status` → 禁用/启用用户
   - `GET /api/admin/shares` → 返回所有分享
5. **前端验证**（浏览器）：
   - 普通用户登录 → 导航栏显示"已用 XX MB"
   - admin 登录 → 导航栏显示"管理后台"链接
   - 进入 admin.html → 四个 Tab 正常切换
   - 非 admin 访问 admin.html → 重定向到 index.html

#### 部署后验证
- 使用 Puppeteer/Playwright 截图验证 UI
- 跨用户秒传后刷新用量显示正确
- 禁用用户后该用户无法登录
