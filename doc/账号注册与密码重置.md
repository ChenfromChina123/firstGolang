# FileSync 账号注册与密码重置模块文档

## 1. 功能概述

FileSync 提供完整的账号生命周期管理：邮箱注册（激活链接验证）和忘记密码（验证码重置）。系统使用阿里云企业邮箱 SMTP 服务发送邮件，支持 465 端口 SSL implicit 加密传输。

### 核心特性

| 功能 | 验证方式 | 有效期 | 速率限制 |
|------|----------|--------|----------|
| 账号注册 | 邮箱激活链接 | 24 小时 | 3 次/小时/IP |
| 忘记密码 | 6 位数字验证码 | 10 分钟 | 3 次/小时/IP |
| 登录 | 用户名或邮箱 + 密码 | JWT 24 小时 | 5 次/分钟/IP |

## 3. API 详细说明

### 3.1 POST /api/register — 注册账号

**请求体：**
```json
{
  "email": "alice@example.com",
  "password": "Pass1234",
  "confirm_password": "Pass1234"
}
```

**校验规则：**
- email：合法邮箱格式，包含 @，域名含 .
- password：至少 8 位，包含字母和数字
- confirm_password：必须与 password 一致

**响应：**
| HTTP 状态 | 响应体 | 说明 |
|-----------|--------|------|
| 200 | `{"success":true,"message":"若邮箱可用，激活邮件已发送，请查收邮箱"}` | 注册成功或邮箱已存在（防枚举） |
| 400 | `{"error":"invalid_email","message":"..."}` | 邮箱格式无效 |
| 400 | `{"error":"weak_password","message":"..."}` | 密码强度不足 |
| 400 | `{"error":"password_mismatch","message":"两次输入的密码不一致"}` | 两次密码不一致 |
| 429 | `{"error":"rate_limited","message":"too many requests"}` | 超过速率限制 |
| 503 | `{"error":"email_service_disabled","message":"邮件服务未配置"}` | SMTP 未配置 |

### 3.2 GET /api/activate — 激活账号

**请求参数：** `?token=xxx`（32 字节 hex 字符串）

**处理流程：**
1. 查询 token 是否存在
2. 校验是否过期（24 小时）
3. 更新用户 status 为 active
4. 删除已用 token（保证一次性）

**响应：** HTTP 302 重定向
| 场景 | 重定向目标 |
|------|------------|
| 激活成功 | `/web/login.html?activated=1` |
| token 无效 | `/web/activate.html?status=invalid` |
| token 过期 | `/web/activate.html?status=expired` |
| 系统错误 | `/web/activate.html?status=error` |

### 3.3 POST /api/resend-activation — 重新发送激活邮件

**请求体：**
```json
{ "email": "alice@example.com" }
```

**响应：**
| HTTP 状态 | 响应体 | 说明 |
|-----------|--------|------|
| 200 | `{"success":true,"message":"若邮箱可用且未激活，激活邮件已发送"}` | 成功（防枚举） |
| 400 | `{"error":"invalid_email","message":"..."}` | 邮箱格式无效 |
| 429 | `{"error":"rate_limited","message":"too many requests"}` | 超过速率限制 |
| 503 | `{"error":"email_service_disabled","message":"邮件服务未配置"}` | SMTP 未配置 |

### 3.4 POST /api/forgot-password — 忘记密码

**请求体：**
```json
{ "email": "alice@example.com" }
```

**处理流程：**
1. 校验邮箱格式
2. 查询用户：不存在也返回成功（防枚举）
3. 用户存在且 status=active：生成 6 位验证码，10 分钟过期
4. 异步发送验证码邮件

**响应：**
| HTTP 状态 | 响应体 | 说明 |
|-----------|--------|------|
| 200 | `{"success":true,"message":"若邮箱可用且已激活，验证码已发送"}` | 成功（防枚举） |
| 400 | `{"error":"invalid_email","message":"..."}` | 邮箱格式无效 |
| 429 | `{"error":"rate_limited","message":"too many requests"}` | 超过速率限制 |
| 503 | `{"error":"email_service_disabled","message":"邮件服务未配置"}` | SMTP 未配置 |

### 3.5 POST /api/reset-password — 重置密码

**请求体：**
```json
{
  "email": "alice@example.com",
  "code": "123456",
  "new_password": "NewPass1234",
  "confirm_password": "NewPass1234"
}
```

**处理流程：**
1. 校验邮箱格式、验证码格式（6 位数字）、新密码强度
2. 查询验证码记录：校验存在性、是否已使用、是否过期
3. 标记验证码为已使用
4. bcrypt 哈希新密码
5. 更新用户密码

**响应：**
| HTTP 状态 | 响应体 | 说明 |
|-----------|--------|------|
| 200 | `{"success":true,"message":"密码已重置，请登录"}` | 重置成功 |
| 400 | `{"error":"invalid_code","message":"验证码错误或已过期"}` | 验证码无效 |
| 400 | `{"error":"weak_password","message":"..."}` | 新密码强度不足 |
| 400 | `{"error":"password_mismatch","message":"两次输入的密码不一致"}` | 两次密码不一致 |

## 4. 数据库表结构

### 4.1 users 表（新增字段）

```sql
-- 增量迁移：通过 ALTER TABLE ADD COLUMN 添加
ALTER TABLE users ADD COLUMN email TEXT;              -- 可空（admin 历史 account 无邮箱）
ALTER TABLE users ADD COLUMN status TEXT DEFAULT 'active';  -- 已有用户默认 active

-- 邮箱唯一索引（NULL 不冲突，兼容历史 admin）
CREATE UNIQUE INDEX idx_users_email ON users(email);
```

| 字段 | 类型 | 说明 |
|------|------|------|
| email | TEXT | 用户邮箱（可空，admin 历史 account 为 NULL） |
| status | TEXT | 账号状态：active（已激活）、pending（待激活） |

### 4.2 user_activation_tokens 表（激活令牌）

```sql
CREATE TABLE IF NOT EXISTS user_activation_tokens (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id VARCHAR(64) NOT NULL,
    token VARCHAR(64) NOT NULL UNIQUE,        -- 32 字节 hex
    expires_at VARCHAR(32) NOT NULL,          -- RFC3339
    created_at VARCHAR(32) NOT NULL
);
CREATE INDEX idx_token_user ON user_activation_tokens(user_id);
CREATE INDEX idx_token_expires ON user_activation_tokens(expires_at);
```

### 4.3 password_reset_codes 表（密码重置验证码）

```sql
CREATE TABLE IF NOT EXISTS password_reset_codes (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id VARCHAR(64) NOT NULL,
    email VARCHAR(255) NOT NULL,
    code VARCHAR(8) NOT NULL,                 -- 6 位数字
    expires_at VARCHAR(32) NOT NULL,          -- RFC3339
    used INTEGER DEFAULT 0,                   -- 0 未使用 / 1 已使用
    created_at VARCHAR(32) NOT NULL
);
CREATE INDEX idx_reset_email ON password_reset_codes(email);
CREATE INDEX idx_reset_expires ON password_reset_codes(expires_at);
```

## 5. 安全设计

| 风险 | 缓解措施 |
|------|----------|
| **邮箱枚举攻击** | 注册和忘记密码接口无论邮箱是否存在都返回通用成功消息，不暴露账号是否存在 |
| **暴力注册** | 注册接口速率限制 3 次/小时/IP（token bucket: rps=0.00083, burst=3） |
| **验证码爆破** | 6 位数字 + 10 分钟过期 + 3 次/小时/IP 限流；验证码使用后立即标记为已使用 |
| **激活 token 猜测** | 32 字节 crypto/rand 生成（64 字符 hex），24 小时过期，使用后删除 |
| **密码弱** | 沿用 ValidatePasswordStrength：至少 8 位，包含字母和数字 |
| **邮箱大小写冲突** | 存储前 NormalizeEmail 转小写去空格，查询时也转小写 |
| **邮件发送阻塞请求** | 使用 `go func()` 异步发送，失败仅记日志不影响响应 |
| **旧 token/code 堆积** | 服务启动时自动清理过期 activation_tokens 和 reset_codes |
| **重复激活** | 同一邮箱重复注册时，清理旧 token 后重新发送激活邮件 |
| **明文密码泄露** | bcrypt 哈希（cost=12），JSON 标签 `json:"-"` 不序列化 |

## 6. 配置示例

### 6.1 systemd 环境变量

```ini
Environment=SMTP_HOST=smtp.qiye.aliyun.com
Environment=SMTP_PORT=465
Environment=SMTP_USER=px-ai@aistudy.icu
Environment=SMTP_PASS=C2OzrpugzVCEMN6F
Environment=SMTP_FROM=FileSync <px-ai@aistudy.icu>
Environment=APP_BASE_URL=https://aistudy.icu
```

### 6.2 配置说明

| 变量 | 必填 | 说明 |
|------|------|------|
| SMTP_HOST | 否（默认 smtp.qiye.aliyun.com） | SMTP 服务器地址 |
| SMTP_PORT | 否（默认 465） | 465=SSL implicit, 587=STARTTLS |
| SMTP_USER | 是（启用注册功能时） | 发件邮箱账号 |
| SMTP_PASS | 是（启用注册功能时） | SMTP 授权码（非邮箱登录密码） |
| SMTP_FROM | 否（默认 `FileSync <SMTP_USER>`） | 发件人显示名 |
| APP_BASE_URL | 否（默认 `https://<DOMAIN>`） | 用于拼接激活链接 |

> **未配置 SMTP_USER/SMTP_PASS 时**：注册/忘记密码接口返回 503，登录功能不受影响。

### 6.3 465 端口 SSL 实现

阿里云企业邮箱 465 端口使用 implicit SSL，Go 标准库 `smtp.SendMail` 不支持，需用 `tls.Dial` + `smtp.NewClient`：

```go
// 1. 建立 TLS 连接
conn, err := tls.Dial("tcp", addr, &tls.Config{ServerName: host})
// 2. 创建 SMTP 客户端
c, err := smtp.NewClient(conn, host)
// 3. 认证
c.Auth(auth)
// 4. 发送邮件
c.Mail(m.from)
c.Rcpt(to)
w, _ := c.Data()
w.Write([]byte(htmlBody))
w.Close()
```

## 7. 测试用例

### 7.1 正常流程

| # | 场景 | 步骤 | 预期结果 |
|---|------|------|----------|
| 1 | 完整注册流程 | 注册 → 收激活邮件 → 点击链接 → 登录 | 登录成功，进入控制台 |
| 2 | 完整重置流程 | 忘记密码 → 收验证码 → 重置密码 → 新密码登录 | 登录成功 |
| 3 | 邮箱登录 | 注册激活后用邮箱登录 | 登录成功 |
| 4 | 用户名登录 | 注册激活后用自动生成的 username 登录 | 登录成功 |
| 5 | 现有 admin | 用 admin/changeme123 登录 | 登录成功（不受影响） |

### 7.2 异常场景

| # | 场景 | 操作 | 预期结果 |
|---|------|------|----------|
| 1 | 未激活登录 | 注册后未激活即登录 | 403 + "账号未激活" |
| 2 | 重复注册 | 同一邮箱再次注册 | 返回通用成功（防枚举） |
| 3 | token 过期 | 24 小时后点击激活链接 | 重定向到 activate.html?status=expired |
| 4 | token 无效 | 篡改激活链接 token | 重定向到 activate.html?status=invalid |
| 5 | 验证码错误 | 重置时输入错误验证码 | 400 + "验证码错误或已过期" |
| 6 | 验证码重用 | 同一验证码重置两次 | 第二次返回 400 |
| 7 | 密码强度不足 | 注册时密码仅字母 | 400 + "password must contain..." |
| 8 | 两次密码不一致 | 注册时密码与确认密码不同 | 400 + "两次输入的密码不一致" |
| 9 | 速率限制 | 1 小时内注册 4 次 | 第 4 次返回 429 |
| 10 | 不存在邮箱忘记密码 | 用未注册邮箱调忘记密码 | 返回 200 通用成功（防枚举） |
| 11 | admin 忘记密码 | admin 账号（无邮箱）调忘记密码 | 返回 200 通用成功（不发送邮件） |

## 8. 邮件模板

邮件使用 HTML 格式，终端美学深色主题，与前端风格一致：
- 品牌色：电光青 #00d9ff
- 字体：JetBrains Mono / 系统默认
- 激活邮件：含激活按钮（链接到 `{APP_BASE_URL}/api/activate?token=xxx`）
- 重置邮件：含 6 位验证码（大字号居中显示）
- 中文内容用 base64 编码确保兼容性

## 9. 维护说明

- **清理过期数据**：服务启动时自动执行 `DeleteExpiredActivationTokens` 和 `DeleteExpiredResetCodes`
- **手动重置 admin 密码**：admin 账号无邮箱，需通过 `FILESYNC_INITIAL_PASSWORD` 环境变量（仅 users 表为空时生效）或直接改库
- **SMTP 故障排查**：查看 `/opt/filesync/server.log` 中 `[Email]` 前缀日志
