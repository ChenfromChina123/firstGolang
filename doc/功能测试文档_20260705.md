## 1. 测试环境

### 1.1 服务器环境
- **地址**: http://8.138.174.80:8888
- **操作系统**: Linux (服务器)
- **部署方式**: systemd 服务
- **存储**: 本地文件系统
- **数据库**: SQLite + Redis (Sentinel 模式)

### 1.2 测试工具
- **API 测试**: curl (PowerShell)
- **Web 界面测试**: Playwright MCP v1.62.0 (Microsoft Edge)
- **验证工具**: Invoke-RestMethod (PowerShell)

### 1.3 测试范围
| 模块 | 测试内容 | 测试方法 |
|------|---------|---------|
| 健康检查 | /api/health 端点 | curl |

| 下载功能 | 完整下载/断点续传 | curl |

| 冲突处理 | 文件名冲突检测 | curl |

| 用例 ID | 用例名称 | 请求 | 预期结果 |

### 2.3 上传模块

| 用例 ID | 用例名称 | 请求 | 预期结果 |
|---------|---------|------|---------|

| UP-003 | 查询上传状态 | GET /api/upload/status | 200, 返回 received_chunks |

| UP-006 | 状态-不存在 | GET /api/upload/status?session_id=invalid | 404 |
