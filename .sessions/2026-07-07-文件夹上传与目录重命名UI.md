#### 改动 3：web/app.js getUploadFilename 改造（核心一行）
[web/app.js:259-261](file:///d:/STUDY/GO/StudyGolang/firstGolang/filesync/web/app.js#L259-L261)：
```js
getUploadFilename() {
    const relativePath = this.file.webkitRelativePath || this.file.name;
    return this.targetDir ? this.targetDir + relativePath : relativePath;
}
```
- 普通文件 webkitRelativePath 为空，回退 file.name（行为不变）
- 文件夹文件 webkitRelativePath 含相对路径（如 "subdir/file.txt"），保留目录结构
