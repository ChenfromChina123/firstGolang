## 排查过程

### 1. 尝试 native_webview2loader tag
- 搜索结果显示：Wails v2.10 已用 go-webview2 v0.1.17 修复 native webview2loader 问题
- 当前 wails 版本：v2.13.0（已包含修复）
- 执行命令：`wails dev -tags native_webview2loader`
- 结果：仍然出现 8000ffff 错误
  - `[WebView2] Environment created successfully`（环境创建成功）
  - `[WebView2 Error] error creating controller with 8000ffff: Catastrophic failure`（控制器创建失败）
  - devserver (34115) 端口未监听
  - Vite devserver (5173) 正常监听

### 2. 生产构建 wails build
- 执行命令：`wails build -tags native_webview2loader -webview2 embed`
- 构建结果：成功
  - 构建耗时：1分10秒
  - 产物路径：`build/bin/filesync-client.exe`
  - 使用 native_webview2loader tag
  - WebView2 embed 模式（嵌入 Runtime）

### 3. 运行 exe 验证
- 启动 exe：`Start-Process filesync-client.exe`
- 进程 PID：28752
- 结果：进程稳定运行，没有因 WebView2 错误退出
- 截图保存：`build/screenshot.png`（290KB，已清理）

## 关键发现
1. **dev 模式 vs 生产模式差异**：dev 模式下 WebView2 控制器创建失败，但生产版本（带 native_webview2loader + embed）能正常启动
2. **8000ffff 错误原因**：环境问题（可能 Windows Server/容器环境对 WebView2 GUI 控件支持有限）
3. **devserver 端口 34115 未监听**：WebView2 错误后 devserver 也停止
