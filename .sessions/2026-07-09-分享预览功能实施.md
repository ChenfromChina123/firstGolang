# 分享文件在线预览功能实施记录

**日期**: 2026-07-09
**任务**: 修复分享文件没有预览功能的问题

## 需求
- 分享页支持文件在线预览
- 支持类型：图片、PDF、文本/代码、音频、视频（MP4 inline）
- 不含 HLS 转码

## 实施内容

### 后端（share.go）
1. `handlePublic` switch 新增 `case "preview"` 路由
2. 新增 `previewShare` handler：
   - 复用 downloadShare 的 token + 频率限制 + 密码校验
   - 不计入下载次数（预览不算下载）
   - 支持 file 类型（直接取 s.FileID）和 dir 类型（按 ?path= 查找）
3. 新增 `serveSharedFileInline` 函数：
   - 参考 preview.go 的 serveContent 实现
   - Content-Disposition: inline（浏览器内联显示）
   - Content-Type: 按 contentTypeFor 设置正确 MIME
   - 支持 HTTP Range 206（视频/音频拖动进度条）

### 前端（share.html + share.js + style.css）
1. share.html：
   - share-actions 新增"预览"按钮（单文件分享）
   - 新增预览 Modal 结构（preview-modal）
   - 更新 style.css/share.js 版本号到 v=20260717
2. share.js：
   - 新增 getFileExt / getPreviewType 工具函数（按扩展名判断预览类型）
   - showContent：单文件分享根据文件名决定预览按钮显隐
   - renderTree：文件行添加预览按钮（仅可预览类型显示）
   - 新增 previewFile / renderPreview / renderTextPreview / closePreview 函数
   - bindEvents：绑定预览按钮点击、Modal 关闭（按钮/backdrop/ESC）
3. style.css：
   - .tree-preview-btn 样式（accent 色调）
   - 预览 Modal 完整样式（大尺寸、各类型渲染器样式、响应式）
