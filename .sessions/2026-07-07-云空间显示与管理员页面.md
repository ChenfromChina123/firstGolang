# 云空间显示与管理员页面开发

**日期**：2026-07-07
**会话主题**：在前端显示用户已使用的云空间，以及专门的管理员页面开发

## 用户需求

1. 前端显示用户已使用的云空间（顶部导航栏）
2. 专门的管理员页面开发（用户管理 + 系统统计总览 + 文件管理 + 分享管理）

## 设计决策

- 存储用量显示位置：**顶部导航栏**
- 管理员页面模块：**用户管理 + 系统统计总览 + 文件管理 + 分享管理**（全选）
- 配额功能：**不需要配额**

## 实施过程

### 第一部分：存储用量显示（顶部导航栏）

1. **db.go 新增统计方法**：`GetUserStorageUsage(owner)` 统计正常文件 + 回收站文件用量
2. **settings.go 新增 API**：`GET /api/storage-usage`，admin 可通过 `?username=xxx` 查指定用户
3. **index.html 导航栏新增**：`<span id="user-storage" hidden>已用 0 B</span>`
4. **app.js 新增**：`fetchStorageUsage()` 函数，登录后自动获取用量

### 第二部分：管理员后台页面

1. **db.go 新增方法**：`ListUsers()`, `ListAllShares()`, `GetSystemStats()`
2. **admin.go 新建**：管理员 handler，6 个 API 端点
   - `GET /api/admin/stats` - 系统统计
   - `GET /api/admin/users` - 用户列表（含用量）
   - `POST /api/admin/users/{id}/status` - 禁用/启用
   - `POST /api/admin/users/{id}/reset-password` - 重置密码
   - `GET /api/admin/shares` - 分享列表
   - `DELETE /api/admin/shares/{id}` - 删除分享
3. **main.go 注册路由**：`mux.Handle("/api/admin/", adminHandler)`
4. **admin.html 新建**：4 Tab 页面（系统总览/用户管理/文件管理/分享管理）
5. **admin.js 新建**：页面逻辑（权限守卫/Tab切换/数据加载/操作处理）

### 第三部分：FileInfoResponse 扩展

发现 `/api/files` 返回的 FileInfoResponse 不含 owner 字段，管理员页面无法显示文件归属。
- **model.go**：FileInfoResponse 添加 `Owner` 和 `Status` 字段
- **file.go**：ListFiles 和 GetFileInfo 填充新字段
- **file.go**：ListFiles 返回空数组 `[]` 而非 `null`（修复前端解析错误）

## 关键技术点

- **权限守卫**：admin.js 的 `checkAdmin()` 调用 `/api/me` 检查 role，非 admin 重定向
- **双重权限校验**：JWT 中间件 + admin.go ServeHTTP 开头检查 `role != "admin"` 返回 403
- **防护机制**：不能禁用自己、不能修改其他 admin 账号
- **XSS 防护**：所有用户输入内容（用户名/邮箱/文件名）通过 `escapeHtml()` 转义
- **时间戳兼容**：`fmtDate()` 同时处理 Unix 秒级时间戳（admin API）和 RFC3339 字符串（files API）
- **全局函数暴露**：admin.js 使用 IIFE 封装，通过 `window.fn = fn` 暴露给 onclick 内联绑定

1. ✅ 系统总览 Tab：5 个统计卡片正确显示（总用户数/总文件数/总存储大小/总分享数/回收站文件）

3. ✅ 文件管理 Tab：空状态正确显示"暂无文件"
4. ✅ 分享管理 Tab：空状态正确显示"暂无分享"
5. ✅ admin.js 正确加载，所有全局函数可用（loadUsers/loadFiles/loadShares/deleteShare）
6. ✅ 权限守卫：admin 登录后可访问 admin.html

### 本地验证注意事项

- 需设置 `ALLOWED_REFERERS=localhost:8080,127.0.0.1:8080` 环境变量，否则防盗链中间件拦截 localhost 请求
- 新数据库需设置 `FILESYNC_INITIAL_USERNAME` 和 `FILESYNC_INITIAL_PASSWORD` 环境变量创建初始管理员
