# Admin 页面设计（admin.html）

> 覆盖 MASTER.md。模式：**数据密集型操作台**（density 8/10，紧凑但可扫读）

## 布局

```
┌────────────────────────────────────────────────┐
│ Topbar: 管理后台 · 面包屑 Home > Admin         │
├────────────────────────────────────────────────┤
│ ┌─────────┬─────────┬─────────┬─────────┐      │
│ │ 总览KPI │ 用户KPI │ 文件KPI │ 分享KPI │      │  ← 4 个统计卡片
│ └─────────┴─────────┴─────────┴─────────┘      │
│ ┌─ Tab: 系统总览 | 用户管理 | 文件 │ 管理 | 分享管理 ┐│
│ │                   数据表格                  │
└────────────────────────────────────────────────┘
```

## 关键规则

1. **KPI 卡**：白底圆角 12px `--shadow-md`；数值 24px 600；标签 13px muted；趋势箭头 ▲绿 ▼红
2. **Tab 切换**：下划线式（active = 2px `--color-primary` 下划线），非胶囊（胶囊=fancy，瑞士风要克制）
3. **表格**：容器白底圆角 8px，表头 `--color-muted` + 600；行 hover `--color-muted`；单元格 padding 12px 16px
4. **行内操作**：`.btn-ghost` 图标按钮（禁用 45° 删除按钮 → 需二次确认 modal），全按钮 `cursor:pointer` + aria-label
5. **分页**：上一页/数字页/下一页，当前页 = 蓝实底白字
6. **空状态**：居中 Lucide 图标（如 Inbox）+ 说明文字 + 可选 CTA 按钮 —— 禁止纯文字 "暂无数据"
7. **密度**：density 8/10 → 间距 tokens 使用 `--space-sm/md/lg`（8/16/24px），不用 xl

## 禁止项

- ❌ 行内直接删除无二次确认
- ❌ 图标按钮无 aria-label（仅图标无文本）
- ❌ 分页/筛选 无 hover/焦点态
- ❌ 表格无边框容器（悬空数据）
