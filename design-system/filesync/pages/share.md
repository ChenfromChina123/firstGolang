# Share 分享页设计（share.html）

> 覆盖 MASTER.md。模式：**单页聚焦卡片**（Lead Magnet 风格：干净白底 + 轻边框 + 品牌色 CTA）

## 布局

```
┌────────────────────────────────────────────────┐
│ Topbar: logo + 产品名（点击回官网）             │
├────────────────────────────────────────────────┤
│        ┌──────────────────────────────┐        │
│        │   分享者头像/名称 + 面包屑    │        │
│        │   文件列表卡片               │        │
│        │   [下载全部] [逐个下载]       │        │
│        └──────────────────────────────┘        │
│        密码门（若受密码保护，替换卡片内容）      │
└────────────────────────────────────────────────┘
```

卡片 `max-width: 720px` 居中；卡片外底色 `#F8FAFC`。

## 关键规则

1. **密码门**：居中 320px 卡，密码框 16px + 显示切换，提交 = `.btn-primary` 全宽；错误提示在字段下红字
2. **文件列表**：Flat 卡片（白底 + 1px `--color-border` 边框，无阴影），行 hover muted；文件类型图标 = 实色圆角方块（蓝/琥珀语义）
3. **目录面包屑**：深度 ≥3 显示（首页 > 目录A > 目录B），可点击返回
4. **预览**：图片/PDF/视频/文本内嵌预览区，`max-height: 70vh` 滚动；加载中显示骨架屏（灰块 + 淡入动画）
5. **下载按钮**：主按钮 = 下载全部（蓝实底），行内下载 = ghost 图标；禁用无文件时置灰 + 禁用态
6. **分享者信息**：头像（首字母圆底蓝）+ 名称 + 分享时间（muted 小字）
7. 移动端：卡片边距 16px，无横向滚动，safe-area

## 禁止项

- ❌ 密码输入无显示切换
- ❌ 预览 loading 无反馈（骨架屏必需）
- ❌ 下载按钮无 hover/active 态
- ❌ 文件名行截断无 title 提示
